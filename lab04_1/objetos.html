Antecedentes


En JavaScript hay 7 tipos de datos primitivos
  1. number : para números de cualquier tipo: enteros o de punto flotante
  2. bigint : para números enteros de longitud arbitraria.
  3. string : para cadenas. Una cadena puede tener cero o más caracteres
  4. boolean : true/false
  5. null : para valores desconocidos
  6. undefined para valores no asignados
  7. symbol para identificadores únicos. Se introdujo en ECMAScript 6.

Y un tipo de dato no primitivo: object para estructuras de datos complejas.

Objetos

  • Los objetos son usados para almacenar colecciones de varios datos y entidades más complejas asociados con un nombre clave.
  • Se crea un objeto usando las llaves {…} 
                
                const objeto = {};    // Esto es un objeto vacío
  • Y opcionalmente con una lista de propiedades.
  • Una propiedad es un par "key:value". Donde "key" es un String y "value" es cualquier cosa. 
    
            const alumno = {
                nombre: "Juan",
                codigo: "2025001",
                ciclo: 5,
              };
  • Se pueden agregar propiedades luego d ehaber creado al objeto: 
    
                // FORMA 1: A través de notación con puntos
                const alumno = {};
                alumno.carrera = "CIS";
                
                // FORMA 2: A través de notación con corchetes
                const alumno = {};
                alumno["carrera"] = "CIS";

  • Si dentro de una variable del objeto metemos una función (o una variable que contiene una función), obtenemos un método de un objeto: 

    
                const alumno = {
                    nombre: "Juan",
                    codigo: "2025001",
                    saludar: function() { return "Hola Mundo"; }
                  };
                  
                  alumno.nombre;       // Es una variable (propiedad)
                  alumno.saludar();     // Es una función (método)
